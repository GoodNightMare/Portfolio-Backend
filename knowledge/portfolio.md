## 12. BuddyBuilder AI

ชื่อโปรเจกต์: BuddyBuilder AI

ประเภท:
- AI Application
- Computer Vision
- RAG
- Web Application

BuddyBuilder AI โปรเจกต์ปี 3 เทอม 2 สมาชิก 4 คน เป็นระบบ AI สำหรับวิเคราะห์พื้นที่จากภาพและให้คำแนะนำเกี่ยวกับการจัดวางเฟอร์นิเจอร์ โดยนำ Computer Vision, Depth Estimation และ RAG มาทำงานร่วมกัน

### แนวคิดของระบบ

ระบบรับภาพห้องหรือพื้นที่จากผู้ใช้ จากนั้นวิเคราะห์วัตถุที่อยู่ในพื้นที่ ตรวจจับเฟอร์นิเจอร์ ประมาณความลึกหรือระยะของวัตถุ และใช้ข้อมูลที่ได้ร่วมกับระบบ RAG เพื่อสร้างคำแนะนำ

### Technologies

Frontend:
- Next.js
- Three.js

AI / Computer Vision:
- YOLO-World
- ZoeDepth

RAG:
- ChromaDB
- BAAI/bge-m3
- Llama 3.3 70B

Database:
- PostgreSQL

### Workflow โดยสรุป

1. ผู้ใช้อัปโหลดภาพห้อง
2. ระบบตรวจจับวัตถุหรือเฟอร์นิเจอร์จากภาพ
3. ระบบประมาณ Depth ของวัตถุ
4. ข้อมูลจากภาพถูกนำไปใช้ประกอบการค้นหาข้อมูล
5. RAG ค้นหา Context ที่เกี่ยวข้องจาก Knowledge Base
6. LLM ใช้ Context เพื่อสร้างคำแนะนำ
7. ระบบสามารถนำข้อมูลไปใช้สร้างหรือแสดง Layout ในรูปแบบ 3D

### หน้าที่ของไนท์

ไนท์มีส่วนเกี่ยวข้องกับ:
- Image Processing Pipeline
- การเชื่อมโยงข้อมูลจาก Computer Vision
- การประยุกต์ YOLO-World และ ZoeDepth

Repository: https://github.com/buddybuilder-ai/app,https://github.com/buddybuilder-ai/core

- หาวิธีปรับแนวคิดของสมาชิกในทีมให้สามารถทำงานร่วมกันได้

## 32. เป้าหมายในอนาคต

ไนท์ต้องการพัฒนาตัวเองในสาย **Artificial Intelligence (AI)** โดยมีเป้าหมายระยะยาวในการทำงานที่เกี่ยวข้องกับการพัฒนาและประยุกต์ใช้ AI เพื่อแก้ปัญหาและสร้าง Software Application ที่สามารถนำไปใช้งานได้จริง

ไนท์สนใจการทำงานที่เชื่อมระหว่าง **Software Engineering และ Artificial Intelligence** ไม่เพียงแค่การสร้างหรือใช้งานโมเดล AI แต่ยังสนใจการนำ AI ไปพัฒนาเป็นระบบหรือผลิตภัณฑ์ที่ผู้ใช้สามารถใช้งานได้จริง เช่น Web Application, Mobile Application และระบบ Backend ที่ทำงานร่วมกับ AI

สายงานที่สนใจ:

* AI Engineer
* Software Engineer ที่ทำงานเกี่ยวข้องกับ AI
* Full-Stack Developer ที่พัฒนาระบบร่วมกับ AI
* งานด้าน Applied AI

หัวข้อ AI ที่สนใจเป็นพิเศษ:

* Natural Language Processing (NLP)
* Retrieval-Augmented Generation (RAG)
* Large Language Models (LLM)
* Vector Search และ Embedding
* Computer Vision
* Object Detection
* Machine Learning
* การนำ AI ไปเชื่อมต่อกับ Web Application และ Mobile Application

เป้าหมายระยะยาวคือการพัฒนาความรู้ทั้งด้าน **AI และ Software Engineering** ให้สามารถออกแบบ พัฒนา และนำ AI ไปใช้งานเป็นส่วนหนึ่งของระบบจริงได้ ตั้งแต่การจัดการข้อมูล การพัฒนาโมเดลหรือ AI Pipeline การสร้าง Backend/API ไปจนถึงการเชื่อมต่อกับ Application ที่ผู้ใช้สามารถใช้งานได้
