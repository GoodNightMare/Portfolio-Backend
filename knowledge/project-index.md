# ดัชนีโปรเจกต์

## ดัชนีโปรเจกต์ตามประเภทและเทคโนโลยี

ดัชนีนี้ใช้สำหรับตอบคำถามที่ถามหาโปรเจกต์หลายรายการตามประเภทหรือเทคโนโลยี รายละเอียดเชิงลึกของแต่ละโปรเจกต์ให้อ้างอิงจากหัวข้อของโปรเจกต์นั้นโดยตรง

- โปรเจกต์ด้าน AI, RAG หรือ Computer Vision: BuddyBuilder AI
- โปรเจกต์ Mobile Application, React Native หรือ Expo: SlideMe
- โปรเจกต์ Full-Stack: HikeCycle และ CourseFlow
- โปรเจกต์ที่ใช้ React: All Game ByNight, Expense Tracker, CourseFlow และ ShingburiShabu
- โปรเจกต์ที่ใช้ Tailwind CSS: HikeCycle, All Game ByNight, Expense Tracker, CourseFlow และ ShingburiShabu
- โปรเจกต์ที่ใช้ C#, ASP.NET Core MVC หรือ SQL Server: HikeCycle
- โปรเจกต์ที่ใช้ Node.js: CourseFlow และ Convert Image
- โปรเจกต์ที่ใช้ Express หรือ MongoDB: CourseFlow
- โปรเจกต์เกมหรือ Game Logic: All Game ByNight
- โปรเจกต์ระบบเช่า: HikeCycle
- โปรเจกต์ระบบลงทะเบียนเรียน: CourseFlow
- โปรเจกต์ระบบจัดการร้านอาหาร: ShingburiShabu
- โปรเจกต์ติดตามรายรับรายจ่าย: Expense Tracker
- โปรเจกต์แปลงไฟล์ภาพ: Convert Image
